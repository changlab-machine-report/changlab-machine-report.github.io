How this is measured

  • Each machine checks once a minute which lab account has processes on each GPU. A GPU-hour is one GPU held for one hour; when two people share a GPU, its time is split between them.
  • Utilization is how busy the GPU was while you held it. Idle GPU-hours are time a GPU was held at under 5% utilization.
  • CPU core-hours and RAM cover everything running under your login sessions. Storage is a snapshot taken when the report was made.
  • Only the five lab accounts are recorded. Weeks run Monday to Sunday, Pacific time.
